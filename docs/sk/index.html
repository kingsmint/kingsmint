Kingsmint

Osobné účtovníctvo z bankových výpisov. Každý výpis sa overí, transakcie roztriedi AI agent a tvoje dáta zostávajú na tvojom počítači.

Windows na ARM: inštalátor pre ARM. Inštalátor pre Windows zatiaľ nie je podpísaný: keď Windows ukáže „Windows protected your PC“, klikni More info a potom Run anyway.

macOS (Apple silicon aj Intel) a Windows. Zadarmo a open source (MIT). · English

Čo robí

Každý výpis sedí

Kingsmint overí každý výpis: počiatočný zostatok + transakcie = konečný zostatok. Žiadna transakcia sa nestratí.

Agent triedi tvoje peniaze

Claude Code, Codex alebo Cursor roztriedi transakcie do kategórií, opýta sa ťa na neznáme a zapíše pravidlá na ďalší raz.

Všetko lokálne

Výpisy aj účtovníctvo zostávajú v priečinku na tvojom počítači. Kingsmint nemá server a nič nezbiera.

Obyčajný Beancount

Účtovníctvo je textový súbor Beancount a prehľady sú vo Fave. Nie si na nič viazaný.

Ako to funguje

  1. Stiahni výpisy zo svojej banky a vlož ich do schránky v appke.
  2. Kingsmint ich prečíta, overí, že každý sedí, a naimportuje transakcie.
  3. Agent ich roztriedi a pýta sa ťa iba na to, čo z výpisov nevyčíta.
  4. Pozri si majetok, príjmy a výdavky v prehľade a vo Fave, alebo sa opýtaj agenta: „Prečo bol môj zisk v marci nižší?“

Appka aj agent hovoria po slovensky.

Iná banka? Daj agentovi jeden vzorový výpis a on pre ňu doplní podporu.

Čo potrebuješ

  • Mac alebo počítač s Windows.
  • Predplatné AI: Claude (Pro alebo Max), ChatGPT (Plus alebo Pro) alebo účet Cursor.
  • Jeho agenta: Claude Code alebo Codex, ktorého appka nainštaluje za teba, alebo Cursor.

Súkromie

  • Výpisy a účtovníctvo zostávajú na tvojom počítači. Kingsmint nemá server a nič nezbiera.
  • Agent posiela to, čo číta (výpisy, súbory účtovníctva, výsledky dopytov), svojmu poskytovateľovi, podľa podmienok tvojho účtu u neho.
  • Prístup na internet: appka sťahuje balíky Pythonu a mesačné kurzy mien z ECB.

Ďalšie spôsoby použitia

  • Plugin pre Claude Code: claude plugin marketplace add kingsmint/kingsmint
  • Aplikácia Claude (chat alebo Cowork): pýtaj sa na svoje peniaze z hociktorého chatu.
