# Ledger

Read `CLAUDE.md`: it describes this ledger, and you follow it as written there. The procedures it names
(`import`, `categorize`, `explain`, `add-bank`) are in `.claude/skills/kingsmint-<name>/SKILL.md`; read the one a
task needs before you start it. `uv run kingsmint skills` copies them from the kingsmint this ledger runs.
